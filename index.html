⚙️ Pengaturan & Integrasi Google Sheet

Tempel URL Web App Apps Script dari Google Sheet kamu supaya konten tersinkron dua arah — tersimpan di sheet dan bisa ditarik lagi di perangkat lain.

📄 Kode Backend (Code.gs)

Belum punya Web App? Buat/buka Google Sheet → Extensions → Apps Script → hapus kode default → tempel kode di bawah → Deploy → New deployment → tipe Web app (Execute as: Me, Who has access: Anyone) → Deploy → salin URL yang diakhiri /exec ke kolom di atas. Sheet "Konten Iklan" akan dibuat otomatis. Untuk konten gambar, link yang kamu isi di kolom "Link gambar konten" dikirim apa adanya sebagai teks ke kolom "Thumbnail" di sheet — bukan file yang diunggah — jadi ikut tersinkron dan bisa ditarik balik di perangkat lain manapun.
